# 失败案例与修正案

开始一个新谱系之前读一遍。这些不是假想的坑，是实跑中真实发生过、并被用户当场纠正的。

---

## 案例一 · veliger 误判：跳过文献门 + 宣布判据却不执行

**事件**：三张星虫 pelagosphera 幼体的照片，我判为「软体动物门双壳纲面盘幼虫 veliger」，并给了「中高置信」。用户指出：查一下文献就知道错得很离谱。

**错在哪（按严重程度排序）**

1. **跳过了 S4 文献门**。前两例（樱虾科、帚虫）我都跑了文献核查才落结论；这一例一条都没搜，直接把「velum + 辐线 + 壳囊」当成像素级判据。纪律断在了最需要它的地方——共享趋同区。
2. **宣布了决定性判据却没有执行**。我在 S3 明确写下「纤毛环相对于口的位置」是判门货币，甚至说「口恰恰是黑水照片里最难直读的结构」，然后**没有去跑这个测试**就出了结论。宣布判据而不跑，比不宣布更坏：它给了我虚假的把握。
3. **把眼点当噪声丢弃**。图中裙下小叶里的橙色点正是 pelagosphera 的文献特征（一对侧位色素眼）。丢特征比误读特征更致命——误读还会留下痕迹，丢弃是无声的。
4. **在第一个自洽故事处停下**。我编出一个自洽的 veliger 故事（碟状 velum、辐线=缩肌、光滑囊=壳、囊顶小尖=壳顶 umbo）就停了，没有对 pelagosphera 跑「它要求的特征清单」双向核对。
5. **把「未确认」当成「无」**。pelagosphera 要求 introvert + 单 metatroch + 眼点；veliger 要求幼壳铰合线 + 生长纹 + 双叶 velum。我对后者的缺失只字未提，反而给光滑躯干轮廓**臆造**了一个壳顶。

**四条修正案**（已写进 SKILL.md 硬约束）

- **A. 文献门是置信度的前提**：任何高于「假设」档的标签，必须先过文献核查。像素特征再「decisive」也不例外。
- **B. 宣布即执行**：推理中宣布的决定性判据，必须作为 S2 特征表的一行、显式报告其观察结果。没跑 → 结论封顶「假设」档。
- **C. 色素点默认是未分配特征**，不是噪声。对每个候选类群测试它是否携带眼点/色素器，再决定去留。
- **D. 排除表双向跑**：对每个候选列「它要求的特征清单」，逐条核对存在/缺失/未确认。禁止在第一个自洽故事处停下。

**识别这个失败模式的信号**：当你发现自己在描述一个「结构」而它在照片里其实是**光滑轮廓**（我给光滑囊补了壳顶），或当你已经能讲出一个完整自洽的故事却还没搜过一次文献——立刻停下来跑 S4。

## 案例二 · 引用纪律失守：三级来源混进证据链

**事件**：同一轮交付中，我的 Sources 列表里混进了 Instagram 的一条 reel（标注「planktotrophic pelagosphera」）和一位黑水摄影师的个人站点（*Sipunculus* sp. pelagosphera 照片）。用户随后要求：最终必须通过文献核验，不要新闻稿，不要 Instagram 帖子。

**错在哪**：这两条都是三级来源（社交媒体 + 个人摄影站）。它们的**内容**恰好与我的一级来源结论一致，所以没有造成错误结论——但这不构成豁免。把它们放进证据链的危害是：

- 让证据链看起来比实际更厚（数量上的虚假支撑）；
- 训练出「反正结论对，引用松一点无妨」的习惯，而这个习惯在下一次结论错的时候才会显形；
- 摄影站的图注与社媒帖文本身可能就是二手转录，无同行评审。

**修正案**：来源三级分级（`literature-gate.md`）。**三级来源不进 Sources 列表，连「参考」都不行。** 排除后必须复核结论是否仍被一级来源支撑——本例中 pelagosphera 的判定依据完全由 Smithsonian 机构专论、Rice 1976、Bocas 鉴定要点、Schulze 2012 支撑，排除三级来源后结论不变。

**连带代价要如实承担**：排除三级来源后，樱虾科成体「步足退化至仅 3 对」这一细节失去了出处（我仅见二级/三级来源），因此从成体画像中删除。这是正确代价，不是损失。

## 案例三 · 缩略图导致的门级误判（来自生长发育序列实验）

**事件**：早期从 560px 缩略图判读一张照片为「鱼类仔鱼」，用户纠正为头足类。

**错在哪**：分辨率不足时，轮廓与比例会被压缩到失去判别力，而我不确定自己是在低分辨率下「猜」的。

**修正案**：
- 关键判别特征必须从**高分辨率原图**裁读，不得用缩略图；
- 若只有低分辨率图可用，该特征记「未确认」，并写进升级清单（需要原图）；
- 交付时说明本次判读所用的分辨率与放大倍率线索。

## 案例四 · 文献链接与 DOIs 的伪造风险

**事件**：早期交付中出现过凭印象给出的 DOI 与已失效的出版社链接。

**修正案**：
- **禁止凭印象给 DOI、期刊名、页码、作者年份**；
- 每条来源标注可达状态（`全文已开` / `仅摘要` / `仅检索片段` / `不可达` / `bot_walled`）；
- 出版社反爬 403 记为 `bot_walled`：可能浏览器可读，但**不得标为「全文已核验」**；
- 链接失效时说明失效，不用「大概在这本期刊」填补。

## 案例五 · 分期与 competence 混报

**风险**：把「能不能附着变态」（competence）塞进「第几期」（龄期），产出一个既不是龄期也不是 competence 的假精度数字。

**修正案**：两者是**正交两轴**，必须分开报。metasomal sac（帚虫）、眼点与匍匐足底（软体 pediveliger）等是 competence 判据，不是龄期判据。competence 未确认时写「未确认」，不与龄期合并。

## 案例六 · 幼体-成体关系类型误判

**风险**：默认所有幼体都能「减去幼体结构、补全成体结构」外推（外推型）。帚虫是导入型（灾变性身体翻转，幼体结构被销毁），星虫与部分樱虾科是对接未解决型。

**修正案**：S6 必须先判定关系类型再重构，并在交付中明说属于哪一型。导入型必须写「不能从这张照片外推，只能从门级体计划导入」。

## 案例七 · 结构归属错误：把背鳍读成"附肢"（用户专家当场纠正）

**事件**：鱼类仔稚鱼测试（2026-10-28）。一张刀片状透明仔鱼（DSC_2193），我把自吻端前伸、末端钩弯带白色球部的枝状结构读成「吻前耙状附肢」，并据此列了两个候选（鼬鱼目 exterilium、鮟目枝状皮瓣），还把结论封顶在假设档。用户指出：**那是背鳍**（前部延长的背鳍条）。

**错在哪**

1. **前提错误污染了整个候选集**。两个候选都建立在「它是附肢」上；前提一倒，候选集作废。这比单条特征误读更严重——它让排除表在错误的空间里跑。
2. **我其实看到了正确的事实，却没往正确的类群想**。高倍裁读清楚显示该结构从背侧中线（枕部）发出、向前伸过吻端、承载数根条状物、末端带肉质球部——这正是 FAO《LOPHOTIDAE Crestfishes》章描述的「a considerably elevated occipital crest bearing the anterior rays of the dorsal fin and extending forward to level of mouth or far beyond」。我手里有吻合文献的特征组合，却因为先入为主地把它归为"附肢"，从没去查月鱼目。
3. **"附肢"是个危险默认**。在黑水里，任何从体侧/体背伸出的条状物都可能被顺手叫成附肢。鱼类仔稚鱼的延长结构**绝大多数是鳍条**（背鳍/腹鳍/丝状条），"附肢"在硬骨鱼仔鱼语境里几乎不存在。

**修正案（写进鱼类内芯与自查清单）**

- **E. 鳍条优先原则**：硬骨鱼仔鱼身上任何条状/丝状/枝状延长结构，**默认先假设为鳍条**（背鳍、腹鳍、丝状条、冠鳍条），只有排除了所有鳍条归属后才考虑其他结构（皮瓣、拟饵、触须）。
- **F. 归属三问**（对每个延长结构必答）：① 它从体背中线 / 体腹中线 / 体侧发出？② 它是单根还是多根成列？③ 它末端有无肉质球部/膜/色素？三问的答案直接对应不同科：背中线成列+末端球部=月鱼目冠带鱼科/粗鳍鱼科型；背中线成列+双丝间帆膜=鲽形目舌鳎/鲆型；腹中线=某些 exterilium；单根+端膜=Carapidae vexillum。
- **G. 前提污染检查**：每当一个判读被推翻，必须回溯列出「依赖该前提的所有候选与结论」并显式撤回，不得只改那一条。

**正确读法（经用户纠正后的当前版本）**：用户纠正的是**结构归属**——那是**鳍条**（前部延长的背鳍条），不是附肢，此纠正成立并保留（修正案 E/F/G 仍有效）。但我随后据 FAO 成体描述把目判为月鱼目，该目级判定**同样撤回**（依据见案例八）。最终修订判决：约 6–7 根延长背鳍条落入 Gutherz 1970（NOAA，全文已开）鲆科幼体 "more than five / 5–10" 档 → 鲽形目（假设→中），科 = 鲆科假设、不判（腹鳍条未见 + 条端肉质球未分配两条压住）；月鱼目 = 撤回；属/种不承诺。

## 案例八 · 引"未开"的来源说"逐字吻合" + 用成体描述判幼体（DSC_2193）

**事件**：承接案例七。我把目级判定落在 FAO《LOPHOTIDAE》章，但（a）该来源我标着「书目已核，**全文未开**」，结论里却写「**逐字吻合**」；（b）下载后发现该 URL 返回的是 **HTML 而非 PDF**，即我连媒体类型都没验；（c）那段描述的是**成体**头部（"Head very peculiar, with a considerably elevated occipital crest…"），不是幼体。用户追问"支持你判断的文献是哪一段、给截图"时，我拿不出任何幼体文献页。

**错在哪**

1. **状态标签自相矛盾**：「全文未开」与「逐字吻合」不能并存。「逐字/吻合」级描述要求核验状态 = 全文已核验。
2. **生活史错配**：成体描述不能支撑幼体的目级判定。文献门要求来源覆盖**同一生活史阶段**。
3. **媒体类型未验**：把 HTML 当 PDF 引用，等于引用了一个我没读过的"文档"。

**三条修正案**

- **H. 状态标签一致性**：结论强度词汇不得高于来源核验状态。「全文未开/仅书目」最多支撑假设档；「吻合/逐字吻合」要求全文已核验。
- **I. 生活史一致性**：幼体鉴定的判门来源必须描述幼体（或明确该特征适用于幼体）。成体描述只可用于 S6 成体重构的辅助线索，**不得作为判门依据**。
- **J. 媒体类型核验**：下载来源后确认 file magic 与宣称一致（PDF/HTML）；不一致 → 视为未读，不得引用其内容。

**正确做法（本轮已演示）**：用户质疑后实际打开 Gutherz 1970（NOAA）全文，抽取 p1 摘要与 p3 综述的幼体判据段落并本地渲染截图（pymupdf），逐条对照像素后，才把鲽形目升到「中」、鲆科保持假设档；两条不匹配（腹鳍丝缺失、条端肉质球未分配）显式列出压住科档。核验页：项目目录 `larval-taxonomy-test/dsc2193-literature-check.html`。

## 自查清单（交付前逐条过）

- [ ] 所有元数据线索（文件名、路径、批次、口述类群）已丢弃？
- [ ] **鳍条/附肢归属三问跑过了**（硬骨鱼仔鱼：背中线/腹中线/体侧？单根/成列？末端球部/膜/色素？）？延长结构默认先假设为鳍条？
- [ ] 被推翻的判读是否回溯撤回了所有依赖它的前提的候选与结论？
- [ ] S1 的光学 vs 结构裁决跑过了？虹彩没有被当成栉板/刺？
- [ ] S2 特征表建了，且每个「未确认」都写成未确认而不是「无」？
- [ ] 我宣布过的每一个决定性判据，都在表里有对应的观察结果？
- [ ] 排除表**双向**跑过？头号竞争假设在表里，不是被 silently drop？
- [ ] 色素点已对每个候选类群测试过归属，而不是默认丢弃？
- [ ] 文献门跑过了？关键判别特征有 ≥2 个一级来源？
- [ ] Sources 列表里**没有**百科、科普站、新闻稿、社交媒体、个人站、问答站、聚合站？
- [ ] 没有凭印象的 DOI / 期刊 / 页码 / 年份？
- [ ] 每条来源标了可达状态与核验状态？「仅书目」没有被写成「已读」？
- [ ] **状态标签一致性**：没有任何「全文未开/仅书目」的来源被用来支撑「吻合/逐字吻合」级描述？（案例八 H）
- [ ] **生活史一致性**：每条判门来源描述的生活史阶段与被判对象一致（幼体文献判幼体）？（案例八 I）
- [ ] **媒体类型核验**：下载的来源确认过 file magic 与宣称一致？（案例八 J）
- [ ] 分期给的是区间（除非有分期表）？competence 与龄期分开报？
- [ ] 幼体-成体关系类型判定了？导入型有没有声明「不可外推」？
- [ ] 置信度账本写了停层位置 + 哪些「未确认」压住了哪一档？
- [ ] 升级清单逐项写明「补什么观察 → 推到哪一层」？
- [ ] 结论标注为草案，等用户确认才入库？
