# 按谱系的判门内芯

SOP 骨架跨门通用，但每换一个门，要换四件内芯：**特征货币、look-alike 集合、分期引擎、幼体-成体关系模型**。本册收录三个已实跑验证的谱系内芯，以及进入「共享趋同区」时的通用协议。

新谱系开工前先读本册：若命中已有内芯，直接套用；若不命中，按「共享趋同区通用协议」执行，并在结束时把新内芯补写进本册。

---

## 内芯一：十足目（Decapoda）幼体

**特征货币**：可数的分节附肢公式 + 刺甲（spination）。标准化程度最高，可跨饲养论文逐条比对，能跑检索表。这是三个内芯里精度上限最高的。

**判门序列与排除依据**

| 门 | 支持特征 | 排除的相似类群 |
|---|---|---|
| 软甲纲 / 真软甲亚纲 | 分节体 + 关节设毛附肢 + 有柄复眼 | 毛颚类（无关节附肢）、翼足类（无壳/翼）、栉水母（8 纵栉板，无附肢） |
| 十足目 | 头胸甲 + 口器篮 + 胸肢序列 + 尾扇（尾肢 4 ramus + 尾节） | 磷虾目（**外露足鳃**是关键排除点）、糠虾目（抱卵育幼，自由幼体罕见；体型计划不符） |
| 枝鳃亚目 | 直而细的腹部、糠虾形游泳姿态、早孵化幼体模式 | 腹胚亚目溞状幼体（体型更紧凑、弯曲） |

**分期引擎**：器官出现序，对照该种饲养论文的分期表。已核验的序列锚点：
- 设毛尾肢（setose uropods）出现于**末原溞状期**，其后变态为糠虾形幼体；
- 樱虾科的糠虾形幼体专称 **acanthosoma**；
- 腹肢仍为芽状 + 尾肢已设毛 = 末原溞状期 → acanthosoma 早期区间。

有饲养论文分期表时可收成点；无表时只给区间。

**幼体-成体关系**：外推型为主，但樱虾科例外——该科存在「只有幼体、成体未知」的幼体型属名（WoRMS 明确记录），所以**科内的幼体-成体对接文献本身就未完全解决**，种级成体肖像从照片不可得。

**成体重构（樱虾科画像）**：小型（厘米级）大洋性虾形十足类，透明至带红色素，眼大；部分属（*Sergia*）具发光器；变态时整套幼体刺甲吸收、腹肢转游泳肢。⚠️「步足退化至仅 3 对」这类细节我仅见二手来源，按来源门应排除，故不写入画像。

**可采纳来源（已核验状态）**

| 来源 | 用途 | 状态 |
|---|---|---|
| Knight 1982, NOAA Tech. Rep.（*Sergestes similis* 幼体发育：nauplius I–IV、protozoea I–III、zoea I–II） | 分期序列 | 书目已核验（机构技术报告） |
| Carreton 2020, *Sci Rep* 10（首原溞状期形态；樱虾科具背刺与侧刺、复眼为头胸甲覆盖） | 科级特征 | 摘要已开 |
| Springer 章节 10.1007/978-94-017-0357-4_2（设毛尾肢出现于末原溞状期 → 糠虾形；樱虾科称 acanthosoma） | 分期锚点 | 检索片段已核 |
| Galathea Report Vol.18（*Sergia* 属修订，含幼体型分类：ortmanni 型 = 侧/后突无侧刺但具长刺） | 属级刺式 | 书目已核验，**全文未开** |
| dos Santos et al., ICES Identification Leaflets for Plankton | 科级幼体检索 | 书目已核验，**全文未开** |
| WoRMS: Sergestidae（记录成体未知的幼体型属） | 停层依据 | 数据库已查 |

**升级清单模板**：①正侧+背面高倍视图 → 读完整刺式，对幼体型图版可到属；②体长 → 对照饲养分期表收成点；③采获水深/海域/日期 → 收窄候选种；④COI/16S → 种级；⑤饲养 → 终局。

## 内芯二：帚虫动物门（Phoronida）辐轮幼虫 actinotrocha

**特征货币**：架构有/无（presence/absence）。特征更少但每个更决断——十足目靠「量」，帚虫靠「有无」。唯一的计数货币是触手数（随龄递增）。

**判门组合（三件套）**
1. 大型草笠状**口前罩**（hood / preoral lobe），覆于口上方；
2. **口后触手环**（postoral encircling array of ciliated tentacles），数十条细长设毛触手辐轮状展开；
3. 后端**末端纤毛环**（telotroch）。
另有 **metasomal sac** = 触手下方腹侧表皮内陷，是 competence 判据（黑水照片常不可见 → 记「未确认」，不与龄期混报）。

**体区**：hood / collar / trunk 三区（University of Oregon 发育记录）。

**排除表（跨门趋同，跨度大于十足目）**

| 排除对象 | 排除依据 |
|---|---|
| 栉水母 | 虹彩为单横环而非 8 纵栉板；有完整盘曲 gut 与触手环 |
| 柱头幼虫 tornaria（半索动物） | 有口前叶与纤毛带，但**无长触手环** |
| 棘皮动物幼体（auricularia / pluteus） | 无骨针或骨板支撑的腕；纤毛带构型不符 |
| 多毛类担轮幼体 | 只有 prototroch 等纤毛带，无 hood+触手环组合 |
| 腕足动物幼体 | 无壳瓣、无四束幼虫刚毛；本类触手为环列长触手 |
| 苔藓动物 cyphonautes | 无三角形双壳 |

**分期引擎**：触手数递增 + competence 标记（metasomal sac 是否成形）。**无通用分期表** → 只能给区间。competence 与龄期正交，必须分开报。

**幼体-成体关系**：**导入型**（三个内芯里最极端）。变态是灾变性身体翻转：hood 被幼体吞入/吸收，幼体触手表皮脱落，telotroch 细胞死亡消失，幼体身体由 metasomal sac 形成，背面变短而腹面变长（Temereva 2015 全文已核）。幼体与成体几乎不共享外部结构 → **不能从照片外推**，只能从门级体计划导入，且必须明说这一点。

**成体（门级画像）**：管栖蠕虫状；几丁质管内；前端马蹄形/螺旋触手冠（lophophore）滤食；U 形肠，肛门位于口背侧、触手冠环之外。

**可采纳来源（已核验状态）**

| 来源 | 用途 | 状态 |
|---|---|---|
| Temereva 2013, *BMC Dev Biol* 13:14（PMC3658900，幼体肌肉发育与变态期重塑；hood 为 preoral lobe 前身） | 架构与变态 | 摘要+图版已开 |
| Temereva 2015, *BMC Evol Biol* 15:204（PMC4618516，metasomal sac 定义、灾变性变态全过程） | 幼体-成体关系 | **全文已开** |
| Strathmann & Bone 1997, *Biol. Bull.* 193(2):153–, DOI 10.2307/1542761, PMID 28575596（口前罩在上游、口后环列纤毛触手；hood 抽吸式摄食） | 判门组合 | 摘要已开；卷期/DOI 经三源核验 |
| Riisgård 2002, *Mar Biol* 141（DOI 10.1007/s00227-002-0802-0；*Phoronis muelleri* 幼体靠触手与口前罩协同捕食） | 判门组合（第 2 源） | 摘要已核 |
| Santagata 2004（PubMed 14994333，*Phoronis pallida* 幼体发育；幼体体型趋同与分异的系统学语境） | 趋同警示 | 摘要已核 |
| University of Oregon 发育记录（hood/collar/trunk 三区；其参考文献著录了 Strathmann & Bone 1997） | 体区 | 全文已开（学位论文） |
| Santagata 幼体发育综述（含幼体检索表线索） | 属级试探 | **仅书目，未开** |

**升级清单模板**：①腹面高倍看 metasomal sac → competence；②多角度精确触手计数 → 对幼体检索表可试探属；③体长；④饲养至变态 → 终局；⑤18S/16S/COI。

**置信度天花板**：门=高；幼体型=高；分期=中后期区间（中）；competence=未知；属/种=**不承诺**。属级需精确触手计数+分子，黑水照片本质不可得。

## 内芯三：星虫动物门（Sipuncula）pelagosphera 幼体

**特征货币**：进入共享趋同区后的通用组合——「纤毛带相对口的位置」+「软组织器官清单」。见下节通用协议。

**判门组合（五特征）**
1. 体区 = **头（introvert）+ 躯干（trunk）两区**，头可缩入躯干；
2. **仅一条横行纤毛带 = metatroch**，位于头/躯干交界、**口之后**（postoral）；
3. **色素眼点**（一对侧位）——常被误当噪声丢弃，实为文献特征；
4. 大洋性浮游营养型呈**玻璃质感大躯干囊 + 显著纤毛裙**；
5. 躯干内含盘曲肠/肾组织团（照片中呈灰褐斑驳团块）。

**关键陷阱**：metatroch 与软体 velum 在黑水照片里外观相近（都是一圈闪光纤毛）。**唯一可靠的裁决是它与口的相对位置**：口在带之前（带为 postoral）→ metatroch → 星虫；口在带之后且带为双叶帆状（velum）→ 软体面盘幼虫。而口恰恰是黑水照片里最难直读的结构 → 找不到口的直接证据时，必须降档并列出两种读法。

**辅助判据**：velum 为**双叶帆状**（bilobed, sail-like）且位于壳口；veliger 的科级鉴定建立在幼壳（prodissoconch）铰合线与生长纹上——若图里连一条铰合线/生长纹都没有，则「壳」的判读不成立，此时报 veliger 属过度自信。

**排除表**

| 排除对象 | 排除依据 |
|---|---|
| 软体面盘幼虫 veliger | velum 为双叶帆状而非单圈连续裙带；无幼壳铰合线/生长纹；纤毛带位置在头/躯干交界缢缩处（= metatroch 位），不在壳口 |
| 帚虫 actinotrocha | 无口前罩、无长触手环 |
| 环节动物担轮幼体 | 无后端封闭大囊 + 腺体团块；纤毛带位置与体比例不符 |
| 栉水母 / 被囊类 / 水母类 | 无 8 纵栉板、无被囊、无辐管-环管构型 |

**分期引擎**：担轮幼虫期 → pelagosphera（部分种为卵黄营养型 pelagosphera，部分为浮游营养型，发育模式共四种：直接发育、单期卵黄营养担轮、两期、浮游营养 pelagosphera）。大洋性浮游营养型 pelagosphera 可在浮游中生活数月 → **分期只能给区间**。 competence 单列。

**幼体-成体关系**：对接未解决型。幼体-成体对接在文献中 famously 未解决（「cosmopolitan species」问题，Schulze 2012），幼体浮游数月、跨洋区分布。**科/属/种：不承诺**。

**成体（门级画像）**：不分级蠕虫状「花生虫」；可翻出的 introvert 带口盘/触手；U 形肠，肛门近口端；穴居或管栖。变态时 metatroch 销毁、头重建为 introvert。

**可采纳来源（已核验状态）**

| 来源 | 用途 | 状态 |
|---|---|---|
| Rice 1976, Smithsonian（*Larval Development and Metamorphosis in Sipuncula*：四种发育模式；浮游营养 pelagosphera 表皮具多样乳突） | 分期与体表 | 机构论文，**全文未开** |
| Boyle, Smithsonian SCMS-42_Boyle_03（*Observations on Oceanic Pelagosphera Larvae: Morphology, Behavior, and Metamorphosis*） | 洋区形态 | 机构专论，**全文未开** |
| Rice 1973, Smithsonian（*Phascolosoma agassizii* pelagosphera 形态、行为与组织发生） | 属级形态 | **全文未开** |
| *Sipuncula (peanut worms) from Bocas del Toro*, Smithsonian（鉴定要点：单横纤毛带 metatroch） | 判门签名 | 机构文献，**全文未开** |
| Schulze 2012（PubMed 22634356，幼体与「世界种」问题；pelagosphera 浮游数月） | 停层依据 | 摘要已核 |
| Adrianov 2008（*Themiste pyroides*：担轮幼虫 → 卵黄营养型 pelagosphera） | 分期 | 摘要已核 |
| Kristof 2011, *Front Zool*（PMC4682194，幼体细胞与肌肉生长模式；躯干被环肌覆盖） | 体区 | 摘要+图版已开 |

**升级清单模板**：①找口的直接证据（高倍看 introvert 前端）→ 确定纤毛带归属，门级从「中高」升「高」；②眼点计数与位置；③表皮乳突（需高倍，浮游营养型特征）；④体长；⑤饲养至变态 → 终局；⑥COI/18S → 种级。

## 共享趋同区通用协议

当多个门共用同一「幼体等级」（如都是担轮幼虫系、靠一条纤毛环游泳的透明幼体）时，独有架构消失，按此执行：

1. **特征货币换成两条更细的证据**：
   - 纤毛环**相对于口的位置**（口前 prototroch / 口后 metatroch；软体 velum 由 prototroch 演化而来，为双叶帆状）；
   - **软组织器官清单**（壳囊+消化腺+足/厣 vs 触手 rosette+盘曲肠管 vs introvert+trunk）。
2. **口的可见度决定置信度天花板**：口是低可见度特征；当判门依赖它而照片里读不到时，天花板自动下调一档。
3. **头号竞争假设必须写进排除表**，不得 silently drop。要写出它「要求的特征清单」，逐条核对存在/缺失/未确认。
4. **禁止在第一个自洽故事处停下**（见 `failure-cases.md` 案例一）。
5. **光学伪影复核前置**：纤毛虹彩在黑水闪光灯下极像结构（栉板、刺、刚毛束），必须先按 S1 裁决规则区分。

## 内芯四：辐鳍鱼纲（Actinopterygii）仔稚鱼 — 两个已实跑幼体型

鱼类仔稚鱼是**共享趋同区的高发地**：多个目共用"透明+延长鳍条/丝状条"的浮游体型。特征货币是**鳍条/棘的延长模式 + 着生点 + 肌节数 + 色素式**。

### 归属三问（对每个延长结构必答，见 failure-cases.md 案例七）

1. 从**体背中线 / 体腹中线 / 体侧**发出？
2. **单根**还是**多根成列**？
3. 末端有无**肉质球部 / 膜 / 色素**？

答案→类群速查：背中线成列+末端球部 = 月鱼目冠带鱼科/粗鳍鱼科型；背中线成列+**双丝间帆膜** = 鲽形目舌鳎/型；腹中线 = 某些 exterilium（鼬鱼目）；单根+端膜 = 珠鳕科 Carapidae vexillum。**硬骨鱼仔鱼的延长结构默认先假设为鳍条**，排除所有鳍条归属后才考虑皮瓣/拟饵/触须。

### 幼体型 A：鲽形目 Pleuronectiformes 仔鱼（鲆科/舌鳎科型）

**特征货币**：极度侧扁透明体；前部背鳍（或腹鳍）丝状延长；**双丝之间张带色素的帆膜**（顶汇于枕部，常带橙斑+银白环）；体侧色素列；变态期眼迁移。

**判门组合**：1. 侧扁透明、无胶质叶状体（排除 leptocephalus）；2. 前部 2 根（或多根）延长背鳍条 + 双丝间帆膜；3. 棒状胸鳍 + 体侧色素列。

**排除表**

| 排除对象 | 排除依据 |
|---|---|
| 鳗鲡目 leptocephalus | 非胶质叶状；已有硬化鳍条、棘列、清晰头眼与色素列 |
| 鼬鱼目 exterilium / 珠鳕科 vexillum | vexillum 为**单根**丝+端膜；本型为**双丝间膜**（已朝鲽形目倾斜但未决时保留为竞争假设） |
| 鮨科石斑类 | 其延长者为第二背鳍棘+腹鳍棘，体细长而非深扁/极细长带帆膜 |
| 白鲳科 *Platax* | 早期仔鱼细长带油球；深体高鳍出现更晚（弱排除） |

**分期引擎**：屈曲前（pre-flexion，2 根延长条）→ 屈曲期（flexion，第 2–4 根延长）→ 后屈曲 → 变态（眼迁移）。*Symphurus* 有论文分期锚点；无表时给区间。眼迁移启动与否是 competence/变态轴，单报。

**幼体-成体关系**：导入型（变态重排：眼迁移、体转不对称卧姿）。成体画像只到科：底栖扁鱼。

**可采纳来源**：Gutherz 1970 NOAA（鲆科仔鱼背/腹鳍条延长，书目已核全文未开）；Evseenko 2008（*Bothus lunatus*，摘要已核）；*Symphurus oligomerus* 仔鱼发育（摘要已核）；SEAFDEC 南海/泰国湾指南（混淆警告，书目已核全文未开）；FAO BOTHIDAE 章 Hensley（全文未开）。

**置信度天花板**：纲/目=高/中高；科=中（假设）；属/种=不承诺。

### 幼体型 B：月鱼目 Lampriformes 冠鳍型（冠带鱼科/粗鳍鱼科）

**特征货币**：刀片/叶状透明体；**自枕部前伸过吻端的冠，承载前部延长的背鳍条**，条末端钩弯带白色球状肉质部；体中线色素列；**无双丝间帆膜**（与 A 型的区分点）。

**判门组合**：1. 前伸枕冠 + 冠上成列背鳍条（FAO Lophotidae 章逐字特征）；2. 末端肉质球部；3. 无帆膜、无腹位丝。

**排除表**：A 型（有帆膜、无前伸冠）；leptocephalus（胶质叶状）；鮟鱇目皮瓣（非背中线成列、无冠）。⚠️ 本型曾被误读为"吻前附肢"——见案例七，归属三问即为此设。

**分期引擎**：该目无可用仔鱼分期表 → 只给"仔鱼期"区间，不承诺期号。

**幼体-成体关系**：外推型弱（冠随发育吸收/降低，体转为带状）；成体画像只到目：大洋性带状/冠鳍鱼。

**可采纳来源**：FAO LOPHOTIDAE 章（书目已核全文未开）；Albano 2022 PMC9598601（地中海月鱼目四科，摘要已核）；琉球大学机构库 *Zu cristatus* 仔鱼记录（书目已核全文未开）。

**置信度天花板**：纲=高；目=中高；科=中（Lophotidae vs Trachipteridae 二向未决）；属/种=不承诺。裁决特征：肛门墨腺（Lophotidae 独有，照片不可见）、冠高、腹鳍幼期延长（Trachipteridae）。

**升级清单模板**：鳍条/肌节计数 → 属或科；着生点高倍（背中线成列 vs 单根）→ 目/科裁决；饲养至变态 → 种；分子（COI/16S）→ 种。

## 内芯五：十足目虾形类（Dendrobranchiata vs Caridea）亚目判别协议

**背景**：虾形幼体在「目」级可防守，但**亚目词汇不可混用**（mysis 属枝鳃、decapodid/postlarva 属真虾；megalopa 属蟹/异尾）。用户曾两次就此提问，本内芯固化判别与词汇规则。

**亚目判别三特征（按可数性排序，原生分辨率裁读，不放大插值）**

1. **螯足对数**：Caridea = 前两对步足螯状（P1、P2）；Dendrobranchiata（Penaeoidea）= 前三对螯状（P1–P3）。数清螯的**对数**与**形态**：caridean 螯细长对称、指节长；penaeoid 螯小而短。
2. **腹节侧突（pleuron）叠压**：Caridea 第二腹节侧突**叠压第一与第三节**（独有衍征）；Dendrobranchiata 各侧突顺序排列不叠压。
3. **第二小颚 caridean lobe**：Caridea 独有（腹面高倍可见）；照片常不可读 → 记「未确认」，不作为否定依据。

**辅助特征**：caridean 幼体常具较长 rostrum 与发达 scaphocerite；penaeoid 幼体（protozoea/mysis）早期腹节侧突圆钝、尾节叉状。鳃型（枝状鳃 vs 丝状鳃）需解剖，照片不可得。

**排除表**

| 排除对象 | 排除依据 |
|---|---|
| 螯龙虾科 Nephropidae | 螯粗壮不对称（碎/切螯分化）、长锯齿 rostrum、体粗壮渐不透明 |
| 龙虾总科 Palinuroidea | 步足无螯；浮游期为无螯叶状 phyllosoma |
| 异尾下目（寄居蟹等） | 腹部不对称/卷曲、螯足形态与体比例不符 |
| 短尾下目（蟹） | 腹部折叠、体型宽扁、具 megalopa 期 |

**词汇规则（硬）**：分期术语是**亚目级**而非目级。Dendrobranchiata = nauplius→protozoea→mysis→postlarva；Caridea = （胚胎 nauplius，不出壳）→zoea I…n→decapodid/postlarva→juvenile。在亚目未决前，**不得**在分期标签里写 mysis 或 megalopa；只写「late larval → transitional（final zoea / decapodid；或 mysis / postlarva if Dendrobranchiata）」。

**可采纳来源（含核验状态）**：de Mazancourt 2022 Sci Rep PMC9613706（Caridea=前两对螯，摘要已核）；bioaccess Caridea 诊断（第二腹节叠压 1、3，摘要已核）；Hertzler 2015 EPA HERO（枝鳃四特征：枝状鳃、前三对步足模式等，书目已核）；FAO y4160e18 PENAEIDAE（齿状 rostrum、P1–3 螯，全文未开）；Brill 幼体系统学（megalopa≠postlarva；仅枝鳃产游离 nauplius，全文未开）。

**置信度天花板**：目=高；亚目=中（需螯足对数+腹节叠压双特征同向）；科=低-中；属/种=不承诺。

**升级清单模板**：腹面高倍数螯足对数与 caridean lobe → 亚目；侧视高倍读第二腹节叠压 → 亚目第 2 证据；饲养/分子 → 种。
