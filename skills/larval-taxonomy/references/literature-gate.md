# 文献门与来源分级准入

S4 之前读。文献门的作用是：**把「我觉得像」变成「有出处可查」**，并让置信度档位有据可依。

## 来源分级（硬规则）

### 一级 · 可采纳（能支撑「高/中高」档）

- 同行评审期刊论文（形态学描述、饲养发育、属级修订、系统发育）
- 机构技术报告与专论：NOAA / FAO / ICES / Smithsonian / 国家博物馆（如 Galathea Report、ICES Identification Leaflets）
- 分类学权威数据库：WoRMS、OBIS、ITIS、Catalogue of Life
- 学位论文（含大学机构库全文，如 scholarsbank、repository.si.edu 中的专论）

### 二级 · 仅作定向线索（不能支撑任何档位的结论）

用途限于：确认术语拼写、找到正确的一级来源、了解类群大致范围。**任何判门结论必须由一级来源支撑。** 引用时标注「⚠️二级，仅作线索」。

- 预印本（bioRxiv / arXiv / EarthArXiv 等未经同行评审者）
- ResearchGate、Academia.edu 等托管页（除非其承载的正文明确来自一级来源，此时引用该一级来源本身）
- 学会或机构的科普性页面

### 三级 · 禁止（一律不进证据链，也不作「佐证」）

用户明确要求：百科类、新闻稿、社交媒体一律排除。完整禁止清单：

- 维基百科、百度百科、搜狗百科、快懂百科及一切 wiki/百科站
- 科普中国、科普网、SciShow 类科普站、科普自媒体
- **新闻稿、新闻网站、通讯社报道**
- **Instagram、Facebook、X/Twitter、TikTok、小红书、微博、YouTube、B站等一切社交媒体**
- 个人网站、个人摄影站、摄影论坛、博客（含 Medium 类）
- 问答站（Quora、知乎、Stack Exchange）
- 内容聚合站（Alchetron、StudyGuides、AI 生成的内容农场）
- 百科类站点（Wikipedia、baike.baidu.com、baike.sogou.com、快懂百科等，任何语种）
- 教学/教材网页（如 byui.edu 一类课程页）：内容可能正确，但非同行评审、常被简化，故仅作二级线索；中文科普站（科普中国 cloud.kepuchina.cn 等）归入三级

**这条规则有真实代价**：排除三级来源后，某些「常识级」细节会失去出处（例如樱虾科成体步足退化至 3 对，我仅见于二级/三级来源）。此时**正确做法是把该细节从结论画像中删掉**，或标注「仅见非可采纳来源，不写入结论」，而不是悄悄引用它。

### 检索结果污染的已知形态

搜索引擎会把百科、问答、聚合站与真正的一级论文混在同一页返回，且百科条目常带「权威」外观（含目录、参考文献）。已知陷阱：

- 同名词跨类群污染：搜 actinotrocha 会返回半翅目 *Acanthosoma*（蝽）的条目；搜 pelagosphera 会返回人体解剖学术语页。→ 每条结果先确认它谈的是目标类群。
- 百科条目里引用的原始文献是**一级来源线索**，但要自己去找到原始出处，不得直接引百科。
- 聚合站会复制论文摘要并加 AI 生成的导语 → 只认原始 DOI。

## 核验流程

### 1. 检索

- 用**结构性术语**检索（如 `actinotrocha hood epistome tentacle telotroch`、`pelagosphera metatroch introvert trunk`），不用类群俗称。
- 一次判门至少跑 2–3 组不同角度的检索：判门特征一组、分期/发育一组、头号竞争类群的排除特征一组。
- 检索失败或超时 → 换词重试一次；仍失败 → 按硬约束 9 封顶假设档。

### 2. 打开全文

只读检索摘要是不够的。摘要常省略「该特征只在某些种出现」这类限定语。打开后记录：

- 来源条目（作者、年、刊/机构、标题、DOI 或稳定 URL）
- **可达状态**：`全文已开` / `仅摘要` / `仅检索片段` / `不可达`
- **核验状态**：`全文已核验`（读了原文并确认它确实这么说）/ `仅书目`（≥2 个独立来源确认该文献存在）/ `未核验`
- 出版社反爬导致的 403 记为 `bot_walled`，不等于不可用（浏览器里可能可读），但**不得标为「全文已核验」**。

### 3. 交叉要求

- **关键判别特征需 ≥2 个独立来源**。单源 → 标注「⚠️单源待校验」，且该特征不能作为停层或升档的唯一理由。
- 多源矛盾 → **标注分歧，不选其一**，把两种读法都写进结论并说明需要什么观察能裁决。
- 数值类结论（刺数、触手数、分期期数、体长）：来源只给定性描述时，**不得自行补成精确数值**。
- 不确定就检索，检索不到就标「未核验」。**禁止凭印象给 DOI、期刊名、页码或作者年份。**

### 4. 引用诚实规则

输出时逐条列出所用来源，每条带「状态」标签。不得：

- 把三级来源写进 Sources 列表（连「参考」都不行）；
- 把「仅书目」的来源描述成「已读」；
- 用一级来源支撑它没说的内容（过度引用）；
- 省略与结论矛盾的来源。

## 文献不可得时的行为

按硬约束 9：

1. 结论封顶在**假设档**，不下类群结论；
2. 给出**候选清单**（含各候选需要哪些特征才能区分）；
3. 说明**需要哪一类文献**才能往下走（如「需要该类群幼体的饲养发育论文或图版检索表」）；
4. 若用户授权，可改用自身知识给方向性判断，但必须显式标注「未经文献核验」。

## 来源清单模板（写进每次交付）

```
| 来源 | 用途 | 状态 |
|---|---|---|
| Knight 1982, NOAA Tech. Rep.（*Sergestes similis* 幼体发育） | 分期序列 | 书目已核验，全文未开 |
| Temereva 2015, *BMC Evol Biol* 15:204 | 灾变性变态 | 全文已开 |
| ⚠️二级/三级来源（若有） | 仅作定向线索，未支撑结论 | 排除 |
```
