把你的裁决判决放在这个目录：
1. 在工作台里逐图裁决（认可1/修改2/否决3 + 分类路径 + 分期 + 备注）
2. 顶栏「保存」导出 workbench_decisions.json
3. 把导出的 JSON 文件放进本目录（文件名任意，.json 即可）
4. 告诉千问"摄取反馈"，脚本会自动：
   - 判决覆盖 AI 草案（人工永远压过 AI，且不可再被 AI 覆盖）
   - correct/reject 写入修正链（旧值留痕）
   - 错题集：你的备注（漏看了什么）+ 失败模式多标签归类（需人工复核）
   - 锚点库：确认图按分类路径归档，未来批次先比对锚点
   - 准确率台账：按批次/层级/失败模式统计
摄取后文件自动移入 _ingested/ 归档，不会重复摄取。
